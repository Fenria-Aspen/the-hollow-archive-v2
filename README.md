# The Hollow Archive

A dark, five-act interactive ARG about forgotten names, hidden ledgers, and the witness who remembers.

## How to Play

1. Start at the landing page
2. Answer five sequential puzzles
3. Each correct answer opens the next act
4. Complete all five acts to become the witness

## Acts

- **Act I**: What is the true name hidden beneath the public one?
- **Act II**: What is the place the archive uses to store forbidden names?
- **Act III**: Decode the Caesar cipher to find the message
- **Act IV**: What is the thing beneath the door, waiting in silence?
- **Act V**: Speak the final phrase exactly as the archive names it

## Setup

Enable GitHub Pages on the `main` branch in repository settings.
